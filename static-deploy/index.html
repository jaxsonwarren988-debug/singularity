Kernel did not start

The interface bundle was served but could not execute. This is almost always a hosting detail, not a broken build. Try these in order:

  1. Name the uploaded file exactly index.html and put it at the root of the site (not in a subfolder).
  2. Upload the file from the dist folder produced by npm run build — it is fully self-contained, with no external asset files.
  3. Make sure the host serves it as text/html. If it is served as plain text or forced to download, scripts never run.
  4. Open the site over https://. Some browsers block storage and crypto on plain http://.
  5. Hard-reload to clear a cached half-upload: Ctrl/Cmd + Shift + R.
